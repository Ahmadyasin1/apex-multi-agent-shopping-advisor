## SEGMENT 3 — Live Pipeline (1:30 – 2:45)

**[Watch the pipeline panel on the left]**

> "Watch the 8 agents run in real-time. Every agent streams its status via WebSocket."

**[Point to each agent as it activates]**

- **Supervisor** → "Agent 1 classifies query complexity — this is 'complex' because it has
  conflicting requirements: high GPU performance AND a budget constraint."
  
- **Preference** → "Agent 2 extracts the priority vector: performance 0.50, price 0.10.
  It also extracts the budget max: $2,000."

- **Retrieval** → "Agent 3 runs FAISS semantic search across 51 products, then filters
  by budget and category. It returns the top 15 candidates."

- **Enrichment** → "Agent 4 normalizes specs — fills missing RAM, storage fields using
  price-based inference. No LLM needed here — purely deterministic."

- **Comparison** → "Agent 5 is the core scoring engine. It computes a 5-axis score for
  each product and runs Pareto optimality analysis."

- **Critique** → "Agent 6 is the quality auditor. It verifies all products are within
  budget and the recommendations make logical sense."

- **Recommendation** → "Agent 7 sends the top products to Gemini 2.0 Flash and generates
  a full advisory report in markdown."

- **Learning** → "Agent 8 persists this session and updates the adaptive preference model."

> "The entire pipeline ran in about [X] seconds. Now let's look at the results."

## Recording Tips

| Tip | Detail |
|---|---|
| **Speak slowly** | Aim for 120–140 words/minute |
| **Pause at key moments** | Let the pipeline run without talking over it |
| **Zoom in on scores** | Use Ctrl+scroll or browser zoom on score bars |
| **Fullscreen browser** | Press F11 for cleaner recording |
| **Microphone quality** | Use a headset for clearer voice |
| **Test run first** | Do a 2-minute practice run to check audio levels |
