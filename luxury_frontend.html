Products are scored across 8 weighted dimensions using Gemini's reasoning capabilities, visualised in an interactive radar chart.

Weighted Scoring Matrix
Each dimension carries a configurable weight derived from user preferences. "Battery" weighs heavier when user mentions travel; "Performance" escalates for gaming queries.
Explainable AI Reasoning
Every recommendation includes chain-of-thought reasoning from Gemini, showing exactly why a product ranks where it does — no black box decisions.
